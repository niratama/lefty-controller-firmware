# WebUI 設定ツール 操作マニュアル (Web Serial Configurator)

左手コントローラー（Waveshare RP2040-Zero 搭載）のブラウザ設定ツール（WebUI）の公式操作マニュアルです。  
専用ソフトウェアのインストールは不要で、対応ブラウザから直接マイコンとシリアル通信（Web Serial API）を行い、キーマップ、スティック動作モード、プロファイルの管理・Hot Reload（オンザフライ反映）を行うことができます。

## 1. 推奨動作環境・アクセス方法

### 対応ブラウザ
* **Google Chrome** (Windows / macOS / Linux / ChromeOS)
* **Microsoft Edge** (Windows / macOS)
* その他 Chromium エンジン搭載ブラウザ（Brave, Opera 等）  
*(※Firefox および Safari は Web Serial API に未対応のためご利用いただけません)*

### 設定ツールへのアクセスURL
* **オンライン版（推奨）:**  
  👉 **[https://niratama.github.io/lefty-controller-firmware/](https://niratama.github.io/lefty-controller-firmware/)**
* **ローカル起動版（オフライン・開発時）:**  
  リポジトリのルートで以下を実行し、ブラウザで `http://localhost:8000` を開きます。
  ```bash
  python3 -m http.server 8000 --directory webui
  ```

## 2. クイックスタート（基本操作の流れ）

```
[1. PC接続] ───► [2. デバイスと接続] ───► [3. 設定編集] ───► [4. デバイスへ保存・反映]
通常モード接続     ポート選択・自動読込      プロファイル/キー/軸      即時 Hot Reload 完了
```

1. **コントローラーをPCに接続する**  
   通常モード（前面ボタン1 `[1]` を**押さずに**USB接続）で接続します。
2. **ブラウザでWebUIを開き「デバイスと接続」をクリック**  
   ポート選択ポップアップが表示されるので、マイコン（**「Lefty Controller - Config Port」**、または更新前の「RP2040-Zero - CircuitPython CDC control」）を選択して「接続」をクリックします。
3. **設定の自動同期 & モニタリング開始**  
   接続に成功すると、デバイス内に保存されている最新設定（全プロファイル・スティック調整値）が自動で読み込まれ、モニタリングが開始されます。
4. **設定の変更**  
   プロファイルの切り替え、キー割り当ての変更、スティックの速度や方向モードの調整を行います。
5. **「💾 デバイスへ保存・反映」をクリック**  
   各タブの上部にある緑色の保存ボタンをクリックすると、マイコンを再起動することなく**オンザフライで新しい設定が適用（Hot Reload）**されます。

## 3. 共通ヘッダー & サイドバー

画面上部と左側のサイドバーは、どの設定タブを開いていても常時利用できます。

### 3.1 接続バーと各種ステータス

画面上部（ヘッダー）には、接続とシステム状態を把握・操作するためのコントロールが集約されています。

| 項目 | 説明 |
| :--- | :--- |
| **💾 ブラウザ保存済 バッジ** | 編集内容がブラウザの `localStorage` にキャッシュされている状態を示します。PC再起動後も直前の編集状態が復元されます。 |
| **FW: vX.X.X バッジ** | 接続中マイコンのファームウェアバージョンを表示します。 |
| **未接続 / 接続中 バッジ** | シリアルポート（CDC）の通信状態を示します。 |
| **デバイスと接続 (Web Serial)** | シリアルポート選択ダイアログを開き、コントローラーと接続します。 |
| **切断** | 通信を安全にクローズします。 |
| **📡 モニタリング開始 / 停止** | スティックの倒しこみ量やボタンの物理入力状態をリアルタイムに受信する通信のON/OFFを切り替えます。稼働中は緑色インジケーターが点滅します。どのタブからでも操作可能です。 |

> [!WARNING]
> ファームウェアが v1.3.0 未満の場合、ヘッダー直下に**「ファームウェアの更新が推奨されます」バナー**が表示されます。D-PadハットスイッチやRun無効化などの新機能を利用するため、メンテナンスモードでマイコンに最新ファームウェアをコピーしてください。

### 3.2 サイドバーとプロファイル切り替え

画面左側のサイドバーで主要機能を切り替えます。

* 📁 **プロファイル:** プロファイルの作成・並び替え・インポート・エクスポート
* ⌨️ **キーマップ:** 13ボタンの入力割り当て（キーボード・マウス・ゲームパッド）
* 🕹️ **スティック:** スティック動作モード（WASD/パッド/マウス）、感度・角度・しきい値設定
* 🧪 **入力テスト:** キー押下テスト、物理ボタンスキャン状態モニター
* ⚙️ **デバイス管理:** 設定全体のバックアップ/復元、デフォルト初期化、生シリアルログ
* **選択中プロファイル（サイドバー下部）:**  
  プルダウンからアクティブプロファイルを即座に変更できます。キーマップやスティックの編集画面から離れることなく素早く切り替えが可能です。

## 4. タブ 1: プロファイル管理

用途（FPS、アクションゲーム、一般作業、フライトシミュレーター等）に応じた複数のプロファイルを一括管理できます。

### 4.1 プロファイルの選択・並び替え・名前変更

* **アクティブプロファイルの選択:**  
  一覧の左側にあるラジオボタン、または行をクリックするとそのプロファイルがアクティブになり、キーマップやスティック設定が即時切り替わります。
* **プロファイル名の直接編集:**  
  行内のテキストボックスから名前（日本語可）を直接書き換えることができます。Enterキーまたはフォーカスを外すと保存されます。
* **並び替え（「▲ 上へ」「▼ 下へ」）:**  
  各行のボタンを押すと、プロファイルの順番を自由に入れ替えられます。

### 4.2 プロファイルの複製・単体書き出し・削除

各プロファイル行の右端にある **「…」メニューボタン** をクリックすると、個別のアクションメニューが表示されます。

* 📑 **複製:** 現在のボタン設定・スティック設定を丸ごとコピーして新しいプロファイルを作成します。微調整のバリエーションを作りたい場合に便利です。
* 💾 **単体書き出し:** そのプロファイルだけを単体の JSON ファイル（`lefty_profile_プロファイル名.json`）としてPCにダウンロード保存します。
* 🗑️ **削除:** 不要なプロファイルを削除します（安全のため、プロファイルが残り1つの場合は削除できません）。

### 4.3 プリセットライブラリからの追加

ヘッダーの **「📚 プリセットから追加...」** をクリックすると、あらかじめ用意された定番テンプレートを選択してワンクリックで追加できます。

* **プロファイル 1 (FPS / 汎用):** WASD移動（浅倒し歩き/深倒しダッシュ）＋ 汎用英数字キー
* **プロファイル 2 (ゲームパッド):** 左スティック ＋ A/B/X/Y/LB/RB等のゲームパッドボタン
* **プロファイル 3 (マウス & 作業用):** スティックマウス移動 ＋ 左/右/中クリック、Ctrl+Z/C/V等
* **プロファイル 4 (4方向スナップ パッド):** 8方向の誤入力を完全に防止した十字キー動作
* **空のプロファイル (新規作成):** デフォルトのクリーンな設定で新しく作成

### 4.4 単体プロファイルのインポート

**「📥 単体読込 (JSON)」** をクリックしてプロファイルJSONファイルを選択すると、既存の設定を壊すことなく新しいプロファイルとして一覧の末尾に追加されます。他のユーザーと設定を共有したい場合に最適です。

## 5. タブ 2: キーマップ設定 (13ボタン)

コントローラーの13個のボタンスイッチに、好みのキーボードキー、マウスボタン、ゲームパッドボタンを自由にマッピングできます。

### 5.1 13ボタンの配置と物理対応

| 番号 | 画面表示 | 物理スイッチ位置 | 初期配置の推奨役割 |
| :---: | :--- | :--- | :--- |
| **0** | 前面 1 | 前面 左上 | メインアクション `1` |
| **1** | 前面 2 | 前面 中上 | メインアクション `2` |
| **2** | 前面 3 | 前面 右上 | リロード / アクション `X` |
| **3** | 前面 4 | 前面 左中 | 使用 / インタラクト `E` |
| **4** | 前面 5 | 前面 中央 | インベントリ / スコア `Tab` |
| **5** | 前面 6 | 前面 右中 | フラッシュライト / 特殊 `F` |
| **6** | 前面 7 | 前面 左下 | スキル / クイック `Q` |
| **7** | 前面 8 | 前面 中下 | 武器切替 `4` |
| **8** | 前面 9 | 前面 右下 | 武器切替 `3` |
| **9** | 側面 1 (上) | 側面 トリガー上 | ジャンプ `Space` |
| **10** | 側面 2 (中) | 側面 トリガー中 | しゃがみ / スニーク `Z` |
| **11** | 側面 3 (下) | 側面 トリガー下 | 伏せ / 修飾キー `LCtrl` |
| **12** | スティック押込 | アナログスティック軸押し込み | オルタネート / ピン `LAlt` |

### 5.2 キー入力とカタログパレット

各ボタンカードの入力欄にキー名を入力します。  
入力欄上部の **「📖 対応キー・アクション一覧カタログ」** を展開すると、使用可能な全キーがカテゴリ別に並んでおり、**チップをクリックするだけで現在選択中の入力欄に自動入力**されます。

### 5.3 複数キー同時押し・マウス・ゲームパッド設定

* **単一キー:** `A`, `Space`, `Enter`, `Esc`, `Tab` 等
* **複数キー同時押し（コンボ入力）:**  
  カンマ区切りで入力します。例: `LCtrl, c` (コピー), `Shift, W` (ダッシュ), `LAlt, F4` (終了)
* **マウス操作:**  
  `Mouse_Left`, `Mouse_Right`, `Mouse_Middle`, `Wheel_Up`, `Wheel_Down`
* **ゲームパッドボタン:**  
  `Gamepad_1` (A), `Gamepad_2` (B), `Gamepad_3` (X), `Gamepad_4` (Y), `Gamepad_5` (LB), `Gamepad_6` (RB), `Gamepad_7` (LT), `Gamepad_8` (RT), `Gamepad_9` (Back/Select), `Gamepad_10` (Start), `Gamepad_11` (LS/L3), `Gamepad_12` (RS/R3), `Gamepad_13` (Guide)

### 5.4 キャプチャモーダルによる入力テスト

各カードの **「テスト」** ボタンをクリックすると、キーボード入力キャプチャモーダルが開きます。キーボードの実際のキーを押すだけで、対応するキー識別子が自動判定されて入力欄にセットされます。

## 6. タブ 3: スティック設定

アナログスティックの入力感度、回転角度、しきい値、出力モードを詳細にカスタマイズできます。

### 6.1 リアルタイム・ビジュアライザ

* **円形レーダー:** スティックの傾きベクトルをリアルタイムにプロットします。
* **内側の円:** デッドゾーン（入力無効領域）の境界を示します。
* **外側の円:** Run（ダッシュ）しきい値の境界を示します。
* **RAW / Delta表示:** ADCの生の16bit読み取り値と、中心（32768）からの偏差を表示します。
* **方向ピル（UP/DOWN/LEFT/RIGHT）:** 各方向の判定状態（`NEUTRAL`, `WALK`, `RUN`）をリアルタイム表示します。

### 6.2 ゼロ点キャリブレーション

スティックに触れていないニュートラル状態で **「ゼロ点キャリブレーション実行」** をクリックすると、現在の物理的なセンター座標をマイコンに記憶させ、スティックの経年劣化や個体差によるドリフトを完全に解消します。

### 6.3 動作モード 1: キーボード (WASD 多段階入力)

PCゲームの移動操作に最適なモードです。

* **Run (走り) を有効化:**  
  チェックを外すと、スティックをいくら倒してもWalkキーのみを出力します。Runキー（Shift等）との同時押しを行いたくないゲームに最適です。
* **方向判定モード:**
  - `8way` (標準): 斜め入力時に縦と横の両方のキーを同時押し（例: `W` + `D`）。
  - `4way_strict`: 最も強く倒されている1方向のみを出力（斜め移動を完全に抑制）。
  - `4way_snap`: 4方向スナップ。
* **スティック回転角度 (0° / 90° / 180° / 270°):**  
  コントローラーを握る手の角度や親指の可動域に合わせて、前進方向の基準軸を90度単位で回転できます。
* **X軸反転 / Y軸反転:** スティックの上下左右を反転します。
* **デッドゾーン / ヒステリシス:**  
  センター付近の遊びと、Walk/Run切り替え時のチャタリング防止幅を設定します。
* **一括設定 & 方向別しきい値テーブル:**  
  上下左右それぞれにしきい値（Walk開始/Run開始）と出力キーを設定可能。「一括設定」ボタンで4方向をまとめて均一に設定できます。

### 6.4 動作モード 2: ゲームパッド (アナログ / D-Pad)

ゲームパッド入力に対応したゲームで使用します。

* **ゲームパッド割り当て軸 (Target):**
  - `左スティック (X/Y)`: 標準的なキャラクター移動スティック。
  - `右スティック (Z/Rz)`: カメラ視点操作スティック。
  - `D-Pad (ハットスイッチ / 十字キー)`: 8方向POVハットスイッチとして動作。
  - `Z軸 (LT/RT アナログトリガー)`: X軸/Y軸をアナログトリガーとして動作。
* **D-Pad Walk / Run 連動ボタン:**  
  D-Pad動作時、スティックの浅倒し・深倒しに応じて特定のゲームパッドボタン（例: ダッシュ用の `Gamepad_2` (Bボタン) や歩き用のボタン）を自動的に同時押しする機能です。
  - `Walk/Runの反転`: 通常ダッシュで浅倒し時のみスニーク（歩きボタン押下）にする動作に対応。

### 6.5 動作モード 3: マウス (ポインタ移動)

スティックでPCのマウスポインタを直接操作します。

* **最高速度 (感度スライダー):** スティックを最大まで倒した際のマウスカーソルの移動速度を 1〜30 の範囲で調整します。

## 7. タブ 4: 入力テスト & ハードウェアモニター

設定したプロファイルが正しくPCへ出力されているか、またコントローラーのハードウェア配線に断線やチャタリングがないかを診断できます。

### 7.1 キー入力テストボックス（フォーカス保護付き）

テキストボックスにフォーカスを当ててコントローラーのボタンを押すと、出力された文字が入力されます。  
`Tab` キーが入力されてもブラウザのフォーカスが別の要素に移動しないよう保護されているため、安全にテストできます。

### 7.2 リアルタイム入力キー表示

PC側で受信したキー入力（修飾キー、通常キー）が画面上にバッジ形式でリアルタイム表示されます。同時押しが意図通り認識されているかを確認できます。

### 7.3 物理ボタンスキャン状態モニター

マイコン側でスキャンしている13個のハードウェアスイッチの物理押下状態（Active Low）をリアルタイムに表示します。  
「キーマッピングの問題なのか、スイッチや配線の物理的な接触不良なのか」を一目で切り分けられます。

## 8. デバイス管理 & ログ

### 8.1 全設定の一括バックアップ & 復元

* **💾 全プロファイル設定書出 (JSON):**  
  全プロファイル、スティック調整値、アクティブ選択状態を含む完全な設定バックアップファイル（`lefty_config.json`）をダウンロードします。
* **📥 全プロファイル設定読込 (JSON):**  
  保存してあったバックアップファイルを読み込み、マイコンとWebUIに一括リストアします。

### 8.2 デフォルト設定への初期化

* **デフォルト設定に戻す:**  
  マイコン内の設定を工場出荷時の初期プリセット（プロファイル1: WASD, プロファイル2: Gamepad, プロファイル3: Mouse）に戻します。

### 8.3 シリアル通信ログ

マイコンとWebUIの間で送受信されているJSONコマンド（`get_config`, `set_config`, `calibrate`, `monitor` 等）や、ファームウェア側の起動ログ、診断出力をリアルタイムに確認できます。不具合の調査時に役立ちます。

## 9. よくある質問・トラブルシューティング

### Q1. 「デバイスと接続」を押してもシリアルポート一覧に出てこない
* デバイス選択ダイアログには **「Lefty Controller - Config Port」**（最新の `boot.py` 適用時）、または **「RP2040-Zero - CircuitPython CDC control」**（または「USB シリアル デバイス」）という名称で表示されます。
* USBケーブルが「充電専用」ではなく「データ通信対応」であることを確認してください。
* マイコンのUSBケーブルを一度抜き差ししてください。
* 他のシリアル通信アプリ（Arduino IDEのシリアルモニタや別のブラウザタブ）がポートを開いたままになっていないか確認してください。

### Q2. 設定を変更したのにゲームに反映されない
* 各タブの上部にある緑色の **「💾 デバイスへ保存・反映」** ボタンをクリックしたか確認してください。
* WebUIの編集内容は、デバイスへ保存を実行するまでマイコン側には反映されません。

### Q3. スティックに触れていないのに勝手に移動する（ドリフト現象）
1. スティックから完全に指を離します。
2. 「🕹️ スティック」タブを開きます。
3. **「ゼロ点キャリブレーション実行」** をクリックしてください。
4. センター座標が正しく再設定されます。

### Q4. PCにドライブ（CIRCUITPY）が表示されない
* **仕様です（正常動作）。** 本ファームウェアは誤操作防止のため、通常時はドライブを非表示にするスマートマウントを採用しています。
* ファームウェアの更新等でドライブを表示させたい場合は、**前面ボタン1 `[1]` を押しながらUSBケーブルを挿入**してください（メンテナンスモード）。
