# 左手デバイス 設定ツール & ファームウェア (Waveshare RP2040-Zero)

PIC18F2450（5V系）搭載の既存左手コントローラーを、**Waveshare RP2040-Zero**（3.3V系）に換装してファームウェアを刷新したプロジェクトです。
13個のボタンスイッチ入力と2軸アナログスティックを備え、**USB Composite Device（Keyboard + Mouse + Gamepad）** として動作します。

キーボードとしての多段階入力（歩き／走り、斜め移動合成）に加え、**アナログゲームパッド（左スティック、右スティック、D-Padハットスイッチ、Z軸）** や **マウス（ポインタ移動・クリック）** としても利用可能で、**Web Serial API によるマルチタブブラウザ設定ツール** からオンザフライで設定・プロファイルの並び替えや単体JSON保存が行えます。

## 1. ハードウェア仕様・ピンアサイン

* **マイコンボード:** Waveshare RP2040-Zero (USB Type-C)
* **スイッチ入力 (13個):** 内蔵プルアップ有効化 / Active Low (押下時GND短絡)
* **アナログスティック (2軸):** RP2040の 3.3V(3V3ピン) と GND に接続 (※5V厳禁)

### ピンアサイン対応表

| ピン番号 | 接続先デバイス | 物理ラベル | 初期キー設定 (Profile 1: キーボード) |
| :--- | :--- | :--- | :--- |
| **GP0** | 前面ボタン 1 (SW1) | `1` | `1` |
| **GP1** | 前面ボタン 2 (SW2) | `2` | `2` |
| **GP2** | 前面ボタン 3 (SW3) | `X` | `x` |
| **GP3** | 前面ボタン 4 (SW4) | `E` | `e` |
| **GP4** | 前面ボタン 5 (SW5) | `Ta` | `Tab` |
| **GP5** | 前面ボタン 6 (SW6) | `F` | `f` |
| **GP6** | 前面ボタン 7 (SW7) | `Q` | `q` |
| **GP7** | 前面ボタン 8 (SW8) | `4` | `4` |
| **GP8** | 前面ボタン 9 (SW9) | `3` | `3` |
| **GP11** | 側面 上 / トリガー 1 (SW10) | 側面上 | `Space` |
| **GP9** | 側面 中 / トリガー 2 (SW11) | 側面中 | `z` |
| **GP10** | 側面 下 / トリガー 3 (SW12) | 側面下 | `LCtrl` |
| **GP12** | スティック押し込み (SW_STK) | STK | `LAlt` |
| **GP27** | スティック X軸 (ADC1) | - | 左右方向 (Left: `A`, Right: `D` / 走り時は `Shift` 追加) |
| **GP26** | スティック Y軸 (ADC0) | - | 前後方向 (Up: `W`, Down: `S` / 走り時は `Shift` 追加) |
| **3V3 / GND**| スティック電源 / 各SWコモン | - | 3.3V 電源 / 共通グランド |

### 回路構成の概要

```text
  [ RP2040-Zero ]
    GP0〜GP8   ---- [ SW1〜SW9 (前面9ボタン) ] -------+
    GP11,GP9,GP10 - [ SW10〜SW12 (側面3トリガー) ] ---+
    GP12       ---- [ SW_STK (スティック押込) ] -----+
                                                      |
    3V3 (3.3V) ---- [ スティック VCC ]                | (共通GND)
    GND        ---------------------------------------+
    GP26 (ADC0) <-- [ スティック VRY (Y軸) ]
    GP27 (ADC1) <-- [ スティック VRX (X軸) ]
```

* スイッチ全13個は内蔵プルアップを活用し、各GPIOと共通GND間に接続するだけのシンプルな外付け抵抗レス構成です。
* スティックの電源には必ず **`3V3`** を接続してください（※5V接続はマイコン破損の原因になります）。
* より詳細な回路結線図、端子配置、部品選定、PICからの改造チェックリストについては **[📖 ハードウェア回路図 & 配線仕様書 (docs/schematic.md)](docs/schematic.md)** をご覧ください。

## 3. スティック動作モードとプロファイルプリセット

本ファームウェアでは、プロファイルごとにスティックの動作モードとボタン割り当てを自由に切り替えることができます。

### 3.1 動作モード
1. **キーボード (WASD 多段階入力):**
   - 浅倒しで「歩き (W/A/S/D)」、深倒しで「走り (Shift + W/A/S/D)」の2段階入力。
   - `enable_run` の切り替えにより、Runを使わない単一速度移動にも対応。
   - ヒステリシス機構（チャタリング防止）と斜め入力合成を完備。
2. **ゲームパッド (アナログスティック / D-Pad):**
   - **左スティック (X/Y):** 標準アナログスティック。
   - **右スティック (Z/Rz):** カメラ操作用アナログスティック。
   - **D-Pad (ハットスイッチ / 十字キー):** 8方向ハットスイッチ出力。4方向スナップと併用で完全4方向入力。
   - **D-Pad Walk / Run 連動ボタン:** スティックの傾きに応じてダッシュボタン（Bダッシュ等）やスニーク歩きボタンを同時押し可能。
3. **マウス (ポインタ移動):**
   - スティックの傾き量に応じた加速度カーブ付きマウスポインタ移動。
   - WebUIから最高速度、通常域上限比率（Walk上限 10%〜90% / 初期値55%）、加速カーブ指数（0.50〜3.00 / 5種クイックプリセット: クイック0.7, リニア1.0, 標準1.5, ハイパー2.0, 超精密2.5）、Run深倒し加速閾値を微調整可能。
   - WebUI上のインタラクティブ Canvas によるリアルタイム速度カーブ描画 & スティック追従表示に対応。

### 3.2 初期プロファイルプリセット
* **プロファイル 1 (FPS / 汎用):**
  - スティック: キーボード (WASD Walk/Run 多段階入力)
  - ボタン: `1`, `2`, `X`, `E`, `Tab`, `F`, `Q`, `4`, `3`, `Space`, `z`, `LCtrl`, `LAlt`
* **プロファイル 2 (ゲームパッド):**
  - スティック: ゲームパッド (アナログスティック X/Y)
  - ボタン: `Gamepad_1`〜`Gamepad_13` (A, B, X, Y, LB, RB, LT, RT, Select, Start 等)
* **プロファイル 3 (マウス & 作業用):**
  - スティック: マウス (カーソル移動)
  - ボタン: `Mouse_Left`, `Mouse_Right`, `Mouse_Middle`, `Wheel_Up`, `Wheel_Down`, `LCtrl, z`, `LCtrl, c`, `LCtrl, v` 等

> [!NOTE]
> プロファイルの JSON フォーマット詳細、13ボタン配列と物理ピンの対応、全対応キー・アクション識別子一覧については [docs/profile_spec.md](docs/profile_spec.md) を参照してください。

## 4. 導入・セットアップ手順

### 4.1 マイコン側への書き込み (CircuitPython)

1. **CircuitPython の導入:**
   * RP2040-Zero の `BOOT` ボタンを押しながらPCのUSBポートに挿入し、マスストレージ（`RPI-RP2`）としてマウント。
   * [CircuitPython 公式サイト (RP2040-Zero用)](https://circuitpython.org/board/waveshare_rp2040_zero/) から `.uf2` をダウンロードし、`RPI-RP2` ドライブにコピー。
   * ドライブ名が `CIRCUITPY` に変われば導入完了です。

2. **ファームウェアファイルのコピー:**
   * **初回セットアップ時:** 本リポジトリの `firmware/` 内の全ファイル（`code.py`, `boot.py`, `config.json`, `stick_engine.py`, `debouncer.py`, `key_mapper.py`, `serial_handler.py`, `config_store.py`, `led_indicator.py`, `ws2812.py`, `hid_keyboard.py`, `hid_mouse.py`, `hid_gamepad.py`）を `CIRCUITPY` ドライブのルートにコピーします。
   * **ファームウェア更新時（2回目以降）:** **`config.json` 以外のファイル** を上書きコピーしてください。`config.json` にはユーザー自身が作成・保存したプロファイルやカスタム設定が含まれているため、上書きすると設定が初期化されてしまいます（`config.json` のスキーマバージョンは WebUI 接続保存時やファームウェア側で自動的に引き継ぎ・更新されます）。
   * **注意:** ファイルコピー後は、必ずOS側で `CIRCUITPY` ドライブを **「安全な取り出し（イジェクト）」** してから、マイコン本体の RESET ボタンを押すか USB ケーブルを抜き差ししてください。

### 4.2 USBドライブ（CIRCUITPY）のマウント制御とメンテナンスモード

本ファームウェアでは、日常利用時にエクスプローラーが開いたり誤ってファイルを変更したりすることを防ぐため、ドライブのマウントを制御しています。

* **通常運用モード (普段の接続):**
  * `CIRCUITPY` ドライブは **PC にマウントされず非表示** になります。
  * USB HID（キーボード／マウス／ゲームパッド）および WebUI 設定用シリアル通信（Web Serial API）のみがスマートに認識されます。
* **メンテナンスモード (ドライブを表示してファームウェアを更新):**
  * **方法 A: WebUI からワンクリック移行 (推奨・v1.8.0〜):**
    WebUIでマイコンと接続中、「⚙️ デバイス・管理」タブの **「🛠️ ドライブ表示 (メンテ)」** ボタンをクリックします。USBケーブルの抜き差しを行うことなくマイコンが自動で再起動し、PC上に `CIRCUITPY` ドライブがマウント表示されます。
  * **方法 B: ハードウェアスイッチによる移行 (フェイルセーフ):**
    前面ボタン1（`SW1` / ラベル `[1]`）を押しながら USB ケーブルを PC に接続します。
* **通常モードへの復帰:**
  * WebUI の **「🔄 通常再起動」** ボタンをクリックするか、PCで `CIRCUITPY` ドライブを「安全な取り出し」した後にマイコン本体の RESET ボタンを 1 回押してください。

> [!IMPORTANT]
> **ファームウェア更新時の注意 (セーフモード防止):**
> PCのOS（Windows/macOS）はファイル書き込みをメモリ上に遅延キャッシュします。ファイルをコピーした直後に取り出しを行わずリセットすると、書き込み不完全により CircuitPython が一時的なセーフモード（`Hard fault`）に入ることがあります。ファイルを更新した後は、**必ずPC側で「安全な取り出し（イジェクト）」を実行してから再起動** してください。万が一セーフモードに入った場合も、WebUI の画面上に表示される「🔄 ソフトリセット (Ctrl-D)」ボタンや本体RESETボタンで安全に通常復帰できます。

## 5. Web Serial API 設定ツールの使い方

Google Chrome または Microsoft Edge 等の Web Serial API 対応ブラウザ（Chromium系）で使用できます。

### 起動方法

* **Web上で直接利用（推奨・インストール不要）:**  
  👉 **[https://niratama.github.io/lefty-controller-firmware/](https://niratama.github.io/lefty-controller-firmware/)**

* **ローカルで起動する場合:**  
  ```bash
  python3 -m http.server 8000 --directory webui
  ```
  ブラウザで `http://localhost:8000` を開きます。

### 主な機能
* **デバイスと接続:**
  * 「デバイスと接続」ボタンを押し、一覧から **「Lefty Controller - Config Port」**（または「RP2040-Zero - CircuitPython CDC control」）を選択。
* **プロファイル切り替え・並び替え・URL共有:**
  * プロファイルの切り替え、直接名前編集、並び替え、複製、単体JSON書き出し・インポート、およびURLリンク（`?profile=...`）によるワンクリック共有。
* **キーマップ設定 (13ボタン / Fnレイヤー / Tap-Hold / 同時押しコンボ):**
  * キーカタログからクリックでキー/マウス/ゲームパッド入力を直感的にマッピング。通常レイヤーとFn裏面レイヤーの切り替え、短押し・長押し（Tap-Hold）の個別割り当て、2ボタン同時押しコンボに対応。
* **スティック・ビジュアライザ & 動作設定:**
  * スティックの現在の倒しこみ座標（Delta X, Delta Y）、動作モード、出力量を円形レーダー上にリアルタイム描画。ゼロ点キャリブレーション機能付き。
* **設定の即時反映 (Hot Reload):**
  * 各タブの「💾 デバイスへ保存・反映」をクリックすると、マイコンを再起動することなくオンザフライで新しい設定が適用されます。
* **メンテナンスモード移行 & セーフモード復帰 (v1.8.0〜 / v1.9.0〜):**
  * 「⚙️ デバイス・管理」タブから、USBを抜き差しせずにワンクリックで `CIRCUITPY` ドライブの表示（メンテナンスモード）や通常再起動が可能。ファイル更新不整合等でセーフモードに入った際も、WebUI 上の「🔄 ソフトリセット (Ctrl-D)」ボタンから安全に復旧できます。

> [!TIP]
> 画面ごとの詳しい操作手順、キー一覧カタログの使い方、スティック調整のコツ、トラブルシューティングについては **[📖 WebUI 設定ツール 操作マニュアル (docs/webui_manual.md)](docs/webui_manual.md)** をご覧ください。
